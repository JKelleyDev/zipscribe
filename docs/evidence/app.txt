[2] The enable/disable decision logic (tray::decide) is a pure, fully-tested transition function:
  - press  & enabled          -> StartRecording
  - release& enabled          -> StopAndDictate
  - press  & disabled         -> Idle (no capture)         [disable stops capture]
  - release& disabled (mid)   -> Idle, back to Idle        [clean stop, discard buffer]
  - no event                  -> Idle (phase preserved)
  These five `decide` unit tests are the verifiable proof that "enabling/disabling correctly
  starts/stops capture and dictation" — the menu items call this exact logic via the enabled flag.

[3] Tray shell (macOS): menu bar icon with items
      Enable dictation / Disable dictation / ─── / Reload config / ─── / Quit
  The Enable/Disable items toggle a shared AtomicBool the dictation worker reads each poll cycle;
  "Reload config" re-reads config; the dictation worker thread owns the resident Whisper model +
  the registered P2T global hotkey. On a no-window-server/headless session `run_tray` degrades to
  running the dictation loop directly, so the LaunchAgent still functions.
