NOTE (historical, archived): in the Ollama era the default was `qwen2.5:7b`. qwen3 had been tried first
via Ollama and, because it is a *reasoning* model, either left residual fillers on short dictation or
spent its budget on internal reasoning and timed out (triggering the under-filling fallback), while
`qwen2.5:7b` removed all fillers + stutter and benefited from a model kept resident in RAM by the
demon. **The current default is no longer an Ollama model.** It is `qwen3-0.6b-4bit` run IN-PROCESS
via MLX (`mlx-rs`) with `light_cleanse` as a safety fallback — see `docs/EVIDENCE.md` §4–5.
