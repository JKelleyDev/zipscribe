=== STARTUP (LaunchAgent auto-start on login) — verbatim evidence ===
Generated by whisperflow-rs `install`, M5 Pro / arm64 / Darwin 27.0.0.

[1] `install` idempotently registers the LaunchAgent in ~/Library/LaunchAgents and loads it:
  $ WHISPERFLOW_BIN="$(pwd)/target/debug/whisperflow-rs" ./target/debug/whisperflow-rs install
  Installed LaunchAgent /Users/jordankelley/Library/LaunchAgents/com.jordankelley.whisperflow-rs.plist \
      for binary /Users/jordankelley/AI-Projects/whisperflow-rs/target/debug/whisperflow-rs \
      (created default config at /Users/jordankelley/.config/whisperflow-rs/config.toml)

[2] launchctl shows the agent loaded with a live PID and last-exit-status 0 (running):
  $ launchctl list | grep whisper
  2723	0	com.jordankelley.whisperflow-rs

[3] The generated plist has RunAtLoad=true (starts on login) + a WorkingDirectory=repo root so the
  relative model path resolves when launchd runs it with its default cwd of $HOME:
    <key>RunAtLoad</key><true/>
    <key>WorkingDirectory</key>/Users/jordankelley/AI-Projects/whisperflow-rs
    <key>ProgramArguments</key> { .../target/debug/whisperflow-rs }
    <key>KeepAlive</key><false/>   (login-start once; not a respawn daemon)
    StandardOut/ErrPath -> ~/Library/LaunchAgents/logs/{out,err}.log

[4] Clean auto-started service log (err.log) — model loads resident, NO panic, NO "config not found":
  whisper_init_from_file_with_params_no_state: loading model from 'models/ggml-medium.en.bin'
  whisper_model_load: type = 4 (medium)
  whisper_model_load:          CPU total size =  1533.14 MB
  whisper_model_load: model size = 1533.14 MB
  PID 2723 remains alive (model resident) after the load.

[5] Install also materializes a default ~/.config/whisperflow-rs/config.toml on first run (never
  overwriting a user's own). Contents include hotkey=ctrl+shift+space, cleanup_model=qwen3:0.6b,
  output_mode=type, cleanup_mode=ollama, ollama_url=http://localhost:11434.

[6] Two latent bugs found & fixed during this task: (a) env_logger::init() was called twice
  (main + dictation thread) which PANICS on re-init — switched all call sites to idempotent
  env_logger::try_init(); (b) the auto-started service ran with cwd=$HOME so the relative model
  path missed — fixed by writing WorkingDirectory=repo root into the plist.
